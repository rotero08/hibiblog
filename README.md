# Hibi (日々)

Blog y guías en español sobre el idioma japonés y la vida en Japón, pensado para lectores de Colombia.

## Qué hay

- Una guía de japonés por etapas, desde los fundamentos hasta el JLPT.
- Una guía de llegada a Japón: preparación, aduana y trámites.
- Un blog sobre Japón y una sección de notas personales.
- Una libreta de sellos que se va llenando a medida que lees las guías.

## Cómo está hecho

Astro con Starlight y MDX. Cada entrada y cada capítulo de las guías es un archivo MDX dentro de `src/content/`.

## Cómo ejecutarlo

```sh
pnpm install
pnpm dev      # servidor local en http://localhost:4321
pnpm build    # genera el sitio
pnpm check    # revisa tipos y contenido
```
